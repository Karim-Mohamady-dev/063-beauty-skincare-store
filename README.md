# Bloom — متجر الجمال والعناية بالبشرة (063)

متجر تجميل تجريبي ثنائي اللغة (العربية RTL والإنجليزية LTR).

## المميزات
- 12 منتجا في فئات العناية بالبشرة والمكياج والشعر والجسم، بأسعار عينة.
- بحث ومرشحات (فئة، مشكلة بشرة، أقصى سعر) وترتيب حسب السعر والرواج والأحدث.
- تفاصيل منتج كاملة: قائمة مكونات ثنائية اللغة، وتقييمات موسومة كعينة للعرض وليست تقييمات حقيقية.
- حالات مخزون صادقة، وسلة ومفضلة محفوظتان في localStorage.
- دفع تجريبي موسوم بوضوح مع تحقق من النموذج وتأكيد طلب تجريبي برقم طلب. لا مدفوعات حقيقية ولا شحن.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## ملاحظات
- عرض تجريبي محلي فقط؛ الأسعار والطلبات والتقييمات غير حقيقية.
